# HQ Sync

Let's you sync with ur moots I suppose!


## Install

1. In-game, open the Dalamud settings: type `/xlsettings`.
2. Go to the **Experimental** tab.
3. Under **Custom Plugin Repositories**, paste this and press the **+**:

   ```
   https://raw.githubusercontent.com/kyo-filet/hq-sync/main/repo.json
   ```
4. Press **Save**.
5. Open the Plugin Installer, search **HQ Sync**, and install it.
6. Open it with `/hq` (or `/hqsync`) and set up your account.
